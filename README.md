# African Debt & Inflation Forecasting

**A learning project by a 16-year-old student exploring time-series analysis, economics and machine learning on African economic data.**

## Motivation
I am curious about how debt and inflation affect African countries and whether simple models can help us understand trends and make rough forecasts. This project is my first step into data science and economic modeling.

## Project Structure
- `data/` : raw and cleaned datasets
- `notebooks/` : Jupyter notebooks with analysis
- `results/` : graphs and forecasts
- `src/` : Python scripts

## How to run
1. Clone the repo
2. `pip install -r requirements.txt`
3. Open the notebooks
